# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately to the maintainers at:

GitHub private vulnerability reporting on this repository (the **Security** tab, then **Report a vulnerability**), maintained by [@bucnazty2020](https://github.com/bucnazty2020).

Include the affected version or commit, the steps to reproduce, and the impact you observed. We will acknowledge the
report and keep you informed while it is investigated.

## Scope

In scope: the miner binary, its pool protocol handling, its configuration and logging, its stats endpoint, and the build
and packaging scripts in this repository.

Out of scope: third-party pools, the Pearl network, GPU drivers and NVIDIA toolkit components, and forks that have been
modified from the official CanaryMiner source.
