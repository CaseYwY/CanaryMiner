# Trademark policy

The CanaryMiner source code is licensed under the MIT License (see [LICENSE](LICENSE)). That license does not
license the name or the logo "CanaryMiner". This policy governs those.

## What you can do

- Use, copy and redistribute **unmodified** CanaryMiner builds and source under the name "CanaryMiner".
- Say that your software is **"based on CanaryMiner"** when you have changed it.
- Refer to CanaryMiner accurately in reviews, benchmarks, guides and support, without implying endorsement.

## What you must do

- If you **modify** CanaryMiner, or distribute a fork or a different program built from its code, rename it. Do not call
  it "CanaryMiner" and do not use the CanaryMiner logo.
- Do not present a modified build as the official CanaryMiner release.

## Developer donation

The optional 1% developer donation described in the [README](README.md) is on by default and can be turned off with
`--no-donation` or `"donation": false`. Running CanaryMiner with the donation off is official and supported: it is still
"CanaryMiner" and needs no new name. Only a renamed or modified fork must follow the naming rules above. The MIT License also
allows anyone to fork the code and change the donation; such a fork must not present itself as the official CanaryMiner build.
Donation windows mine on F2Pool to the developer's account; they do not use the miner's configured pool or account.
