M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-113.

**English-only native source extraction with independent typed draft rendering.** Thirty-four stable `settings.action.*`
and `settings.notice.*` keys across sixteen packs (544 texts) cover the root navigation rows, the hide-worker checkbox,
capability/privacy/effective-language notices, inactive-backend explanations and two root change-refusal messages. Thirteen
unique keyboard entry rows retain exact `[Enter]` tokens. The root still calls English-only helpers; no requested draft
language becomes effective and no ordinary renderer starts ICU or a helper/backend because a catalog entry exists.

These notices preserve their existing limitations: hide-worker is presentation only and does not anonymize logs/API/files;
runtime defaults apply only on the next explicit start; manual references are not polling, actual income or optimization;
non-Off game and requested TLS declarations still refuse ordinary startup; donation consent stays independent; English and
legacy formatting remain effective; session board estimates are not whole-PC/incremental/shared-bill/net-income evidence;
filtering does not stop pipe draining. A translated entry is neither a capability registry nor mining/safety/financial
authority. Existing route indices, save boundaries, pending/recovery controls, no-auto-restart and stop semantics stay intact.

The typed wrappers reuse the bounded fixed-domain bridge. The one `{state}` argument must be exact invariant ASCII `x` or
a single space; other entries take no arguments. Source helpers likewise reject unsupported marks, supplied arguments on
literal-only entries and invalid keys. Layout/color/row publication is transactional, and source role/tone provenance
survives clipping and ordering. Unknown language metadata and whole-English ASCII/backend recovery follow the earlier
contracts. Texts retain the literal keyboard/protocol/reference tokens `[Enter]`, `PRL/USDT`, `FX`, `TLS`, `CLI`, `API`,
`URL`, `1h` and `docs/feature-roadmap.md` where present; these display tokens are not parsers or new runtime options.

Legacy notice lines remain separate keys in their original order, including the paired backend/safety sentence; this is
not rich-text reflow or a new native line-breaking implementation. Every non-English entry remains machine-assisted draft
and still requires human contextual review. Long synthetic strings passing layout do not qualify physical terminal/font,
Arabic shaping, accessibility or discoverability.

Tests cover all 544 texts, exact key/review/direction/placeholder/keyboard/reference-token parity, both checkbox marks,
order/direction/width/paint matrices, all notices in wrapped rows and complete invalid-request/output preservation. A private
fixed-predecessor harness checks **61440 complete native frames**, **786432 complete review vectors** (all legal drafts
against default and reverse), plus **6336 root key transitions and resulting frames** with empty backend/save access. The
last set includes the synthetic unsupported-field/refusal route; it is not qualification of real stores, authorized backend
operations or live workers. Exact platform/sanitizer/privacy evidence is in the [execution ledger](architecture/execution-plan.md).

This completes these root action/notice strings only, not subpanels, control-opening/load/TTY diagnostics or raw backend
errors, dashboard/log domains or effective typed native/data-owner/deployment binding. Human and physical terminal review
and genuine GPU/game/pool/power/financial/release qualification remain open. Existing native/CLI/PTY/store/supervisor
regressions remain separate evidence, and no installed production miner is changed.
