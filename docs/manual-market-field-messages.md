# Manual/offline-reference field labels (P-13ad)

M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-129.

**English-only native source extraction and independent typed drafts.** Eight stable `manual_market.field.*` literal keys
in sixteen packs (128 texts) cover the ordered display, PRL price/reference, independent FX enable/price/reference, validity
and maximum reference-time skew labels. PRL, USDT/PRL, FX, USD/USDT and UTC identities remain explicit and are not selected
from the language, locale, tariff jurisdiction or presentation currency. Non-English entries remain machine-assisted drafts,
not human-reviewed translations or effective native UI.

Only the native private field-label helper changes. Exact English labels, field/page/focus/scroll order, current/configured/
CLI precedence, contextual input, explicit NOW stamping, confirmation, review/save/cancel and JSON serialization remain.
The unchanged positive-decimal/integer parser keeps all original input bounds and units. Price values, Unix reference times,
validity/skew integers, on/off, messages and raw parser/store/callback errors are not translated by this label extraction.
Literal seconds in a human label do not establish a localized numeric/unit binding. Display language cannot change the
asset/quote direction, interpret local time as UTC, refresh a reference, equate stored confirmation with quote time, assume
a stablecoin peg, supply a provider quote or qualify income, a forecast or an economic-control input.

The separate argument-free `TerminalManualMarketFieldMessageRequest` and four layout/wrap/paint wrappers accept no price,
FX, quantity, timestamp, private identity or source facts. Complete English ASCII/disabled recovery, requested/rendered
review metadata, literal tone, source/control/cell provenance, independent wrapped rows and transactional refusal reuse the
shared pipeline. Ordinary native rendering calls no typed renderer or ICU. Preferences and the manual-reference projector
import no catalog and retain their existing validation, clock-latch, expiry and no-mining authority.

Fixtures check all 128 texts, exact English/unique keys/eight-field order, review/RTL/no-parameter and protected identity
tokens, every order/direction/width/plain/paint/provenance/independent-wrap mode and output preservation on invalid key,
language, tone, policy, row budget or null output. A new private fixed-`7a1c369` predecessor comparison runs before and after
extraction: **131072 complete frames / 38912 contextual transitions, resulting frames and active/draft serializations**,
with empty save access. Synthetic vectors span empty/PRL-only/independent-FX/bounded-decimal references, validity/skew limits,
idle/running/CLI-disabled/distinct-effective states, clean/dirty drafts and all fields/pages/terminal dimensions/colors.
Developer-only editor states are compared as rendering behavior, not new parser admission. Actual native store/projector/
CLI/PTY regressions remain separate. Exact platform/sanitizer/privacy results are in the [execution ledger](architecture/execution-plan.md).

Manual shell/diagnostics/dynamic values, other panels/dashboard/log/raw domains, effective typed native/data-owner/deployment,
human review and physical terminal/font/shaping/accessibility remain open. Public-feed/reward/credit attribution, real power/
safety/game/GPU/TLS, global quarantine and production release gates are not supplied by human labels.

[P-13ae](manual-market-notice-messages.md) later extracts local editor/save/explicit-clock notices. This eight-field domain's
historical results and value-free scope remain unchanged; neither extraction activates translated native rendering.
