# Pool field/value, slot and private-input envelopes (P-13ab)

M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-127.

**English-only native source extraction and independent typed drafts.** Ten stable `pool.value.*` keys in sixteen packs
(160 texts) cover machine-request and separate human-value field envelopes, numbered user-pool labels, independent donation,
unset/consent/action descriptions and private editor input. Non-English entries remain machine-assisted drafts, not effective
native translations or reviewed security guidance. Literal YES/off/Enter/TLS and keyboard tokens remain explicit.

Native settings selects exact English source, retaining seven-field order/focus/scrolling, private ASCII byte-tail input,
current-session freeze, review/save/cancel, fixed consent/removal phrases, raw errors and JSON serialization. Mode and set
endpoints use the machine-value envelope; scope/unset/consent/action descriptions use the human envelope. Numbered review
headers share the same English user-pool template. **Before/after full rule summaries are not extracted in this batch**;
their original mode/TLS/TCP/consent display bytes remain independent.

English expansion is nonrecursive, with at most two exactly named arguments, printable ASCII originals at most 300 bytes
each and bounded complete output. Reordered names work; duplicate/missing/extra names, invalid keys, controls and oversized
arguments refuse. Braces in input stay literal. The 300-byte display ceiling is not URL admission: the unchanged DNS/scheme/
port parser still rejects credentials, paths, IP literals and other invalid endpoints. The editor still admits at most 300
printable ASCII characters. Display does not canonicalize, verify, connect, acknowledge consent or delete a pool.

The separate `TerminalPoolValueMessageRequest` and four wrappers require invariant ASCII for machine field values, slot
indexes and private input; the human-value envelope instead requires a non-invariant value with its own explicit recovery.
Both original and recovery bytes are capped at 300 before shared validation, even in disabled/ASCII mode. Slot indexes are
technical ASCII labels, not localized counts/plural claims. Invariant values cannot substitute recovery or partially clip;
a too-wide atomic endpoint refuses wrapped-row publication rather than splitting it. Human unset/action descriptions are
not serialized machine values or command receipts. Complete English recovery and requested/rendered review/provenance/tone
metadata remain transactional. Ordinary rendering still calls no typed renderer or ICU; low-level preferences import none.

Fixtures cover all 160 templates/texts, exact English/key/parameter/review/RTL/protected-token parity, one-pass/reordered/
empty/300-byte expansion, machine/human role refusals, original/recovery bounds, every order/direction/width/plain/paint/
independent-row mode and unchanged failures. A synthetic 253-character DNS endpoint checks intact versus omitted atomic
display and all-or-nothing wrapping; it is deliberately an opaque display request, not a connection or URL-validation test.
Fixed-predecessor comparison remains **258048 native frames / 91392 contextual transitions, resulting frames and active/draft
declaration serializations**, with empty save access. Native store/CLI/PTY/fallback/transport tests remain separate. Exact
evidence is in the [execution ledger](architecture/execution-plan.md).

Full rule-summary/other domains, effective typed native/data-owner/deployment, human translation review and physical
terminal/font/shaping/accessibility remain open. No TLS/trust/egress/fallback/donation/deployment, global quarantine or real
GPU/game/financial/power/safety/release qualification is supplied by these display envelopes.
