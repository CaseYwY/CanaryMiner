## Original event contract

`WorkerWorkPublisher` implements the existing worker-thread `CompletedWorkSink`. An explicit Start precedes sequential Begin, Completed, boundary and reconciled End events; explicit Finish closes the whole source only when no run remains open. Failed verification or an unreconciled end preserves the rejected original when possible and refuses further source use. Queue/callback refusal is terminal and propagates through the opted-in run's existing failure path. Callbacks do not read sensors, write files, sleep, launch processes or perform IPC.

Each strict `CMWW1` frame binds the full parent/worker key, parent epoch, logical slot, worker generation, contiguous event ordinal, original UTC/monotonic observation, exact integer work/attempt/MAC factors, explicit lane and actual installed host wait. Unused fields have a single canonical zero/User representation. No float, display rate, share count, queue time or newly sampled delivery clock replaces an original. All eight event types, maximum integer fields and malformed/noncanonical input remain inside the **unchanged 384-byte** frame limit. Existing CMWC1/CMWC2 and CMWA1/CMWA2 bytes and the 16-frame/chunk parser limits are unchanged.

The child and parent must opt in independently. Unsolicited raw frames at an ordinary parent are protocol faults, not capability negotiation or implicit activation. The child verifies every submitted binding against its actual adopted control gate; the parent verifies against its launched incarnation. Start must be ordinal 1, each successor must be contiguous, and no event can follow Finish. Native OS channel/parent identity and handle-inheritance checks are still those of the existing worker transport. Provisioned private worker keys also namespace the replayed boundary source; counter epoch is the actual worker generation. This does not establish a GPU/driver identity or permit reuse in another incarnation.

## Bounded delivery, backpressure and stop

The child owns at most 32 queued immutable raw frames plus one partially written channel frame. A full queue faults the source/control gate instead of dropping, overwriting, decimating or restamping a record. Each queued frame retains the current command's original deadline. The IO thread continues to read commands, prioritizes changed control receipts over new raw frames, and performs the actual nonblocking writes. `flushedWorkSequence()` proves only local complete-write progress; it is neither peer consumption nor a control acknowledgement.

Opted-in parent reads are capped at 384 bytes per poll so a burst of short records cannot exceed the unchanged parser frame-count bound. Polls return raw events separately from receipts and redacted-log input. Actual process reaping does **not** discard a buffered raw tail: bounded later polls continue until EOF. `workStreamComplete` needs Finish, clean drained EOF, complete framing and no transport fault. Missing Finish, an unfinished frame, intentional cancellation and unconsumed tail never become complete history. No last timestamp or counter is extrapolated to process exit.

The optional `WorkerProcessOwner` path also keeps at most 32 complete original events for `takeWork()`. A full inbox revokes and closes the owned channel rather than silently losing source continuity. Explicit stop revokes publication before joining; previously retained originals remain inspectable, but cannot revive the source or become new commands. After actual reaping the owner gives raw EOF only its existing finite drain budget. Unexpected incomplete EOF faults that opted-in owner. Both collection flags default to false; ordinary workers, retries and fleet behavior are unchanged.

## Independent exact replay

`WorkerWorkReplay` borrows the identical explicit-parent intent/token, checks full incarnation and sequence, and feeds each original into the existing `CompletedWorkCapture`. Parent generation, counter epoch, exact separate user/donation totals, work shape, run bounds, original no-work brackets and cumulative clock guards are therefore recomputed rather than trusted from a remote summary. Stop, gaps, duplicate/reordered events, foreign identities, invalid boundaries, drift, verification failure and unreconciled closure refuse. Finish checks original cumulative clock consistency without extending the last interval or restamping the final lifecycle observation.

Replay and transport completeness are distinct: a completely delivered stream can still contain invalid work and fail replay. Neither completeness result admits native observations into the fixture-qualified measurement/economic modules. A later source coordinator must still bind current original command settlements, independent complete running-energy coverage, known physical measurement support, full device/software identity and safety/game/drift evidence. Raw Pause-only power cannot substitute for running energy.
