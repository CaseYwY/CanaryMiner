remain; token parity does not validate the translation, a choice, a declaration, a clock or actual source facts.

changed/future original messages remain raw, never silently replaced by stale wording. This equality check is not parsing,
source qualification or permission. The model/parser/store import no UI catalog or bridge. Raw store/callback errors and
electricity-model status descriptions remain outside this batch.

as synthetic mappings, not claimed as runtime fault-injected guard coverage.

safe renderer or choice validator. Ordinary native rendering calls no typed renderer or ICU.

No helper/store/device action, persisted receipt, supplier approval, automatic reset, billing/optimizer/runtime activation
or mining restart is added. No message is parsed into preferences, model fields, clocks, JSON, choices or permissions, and
this extraction adds no private log/public-diagnostic copy. Original raw outcomes remain separate from display metadata.
