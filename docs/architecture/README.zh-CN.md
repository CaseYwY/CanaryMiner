# 架构书：中文执行入口

英文主文档面向公开仓库；这里帮助快速确认要求，具体合同以对应编号为准。**架构设计不等于功能已实现。**

## 最终确定的收益口径

- 接受数：滚动24小时／7天／30天／从本地开始记录以来的累计；注明覆盖范围，捐赠份额分开。
- 币价：近1小时等时间均价＋最新报价，明确来源、币种、更新时间和过期状态。
- 今日预估：所选时区的今日已记账收入＋今天剩余时间预测，说明假设；不是一律乘24小时。
- 实际收入：矿池能够归属的实际代币入账，显示近24小时和累计；余额、提现和接受份额不能充当实际收入。
- **主面板按最新价格折算产出参考价值。逐笔估值仅为详情中的可选历史参考。** 此为最终确认，覆盖此前的逐笔主面板方案。
- 无法知道是否已出售；不把估值称为实收美元、已实现利润或当前持仓。USDT也不等于USD，美元显示需要有效换算数据。
- 不填写电价就完全隐藏净利润；填写后允许明确标注GPU板卡功耗口径的估算，但不保证整机实际净赚。

## 功能与模块

1. 原生终端设置：S进入、方向键/Tab导航、空格/回车编辑、V/F2审阅、显式保存、Esc返回；停止优先。
2. Details/Log：分别开关入口和页面，还能调整详情字段、日志级别/条数/时间/跟随；显示过滤不改变后台记录。
3. 收益自动调节：按实测曲线、电价、行情和收益校准挑选安全候选中的最高单位真实时间估算净收益，不是只追求算力或能效。
4. 多个时钟分别可调：采样、预热、测试时长/次数、价格窗口/刷新、经济复查、重测、过期/重试，不能混作一个频率。
5. 游戏：关闭联动／暂停挖矿／测试后共存；游戏体验合格后才在合格候选中择优，退出游戏恢复普通候选。Steam出现只能证明联动，不能证明游戏帧率。
6. TLS：优先安全连接，证书/域名验证；每个矿池先授权才可在规定连接故障后回退明文，证书错误不降级。
7. 多国电价：国家不是价格。规则、地区/供应商/套餐、币种、时区、账期、阶梯、峰谷、动态负价、税费等分开建模；复杂需量、预付费、光伏出口必须声明能力范围。
8. 多语言：首个国际化阶段的16个语言标识见终端规格，支持回退、宽字符、组合字符和RTL；不改变CLI/API键名、计费或资产身份。
9. 安全隐私：不复制本机路径、钱包、GPU标识、私有电价/曲线/实验结果；不自动重启/重载驱动，不隐式开机挖矿，不绕过反作弊或关闭游戏。
