# Literal Game shell, editor and limitation notices (P-13w)

M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-122.

**English-only native source extraction with independent typed drafts.** Thirty-three stable `game.panel.*` literal keys
in sixteen packs (528 texts) cover titles/footers/short-window/leave/review/save/default notices, four contextual editor
validation messages, current-session unavailable/frozen headings and scope/safety/Coexist/no-activation limitations. The
earlier nine [field/human-scope labels](game-field-messages.md) remain a separate historical domain. Non-English entries are
machine-assisted drafts, not human-reviewed translations, effective native UI or game qualification.

Native Game settings explicitly selects English-only helpers, retaining the exact old strings, field/page/row/scroll order,
input handling, draft/save/discard/error paths and machine serialization. Nonempty callback errors and preference/parser/
store validation originals are not interpreted or translated by this extraction. The four editor messages retain their
existing integer ranges and ASCII basename constraints; the renderer supplies no validation authority. All keyboard tokens,
`Q/D/L/S`, `Esc`, `CLI`, `off`, `Coexist`, file/range/unit tokens and `[End of game defaults]` remain explicit. Q/D/L/S stay
editor input rather than global shortcuts, and Ctrl+C still stops under the existing controller.

The separate argument-free `TerminalGamePanelMessageRequest` and four layout/wrap/paint wrappers accept **no target input,
mode, timing, credentials or private identity**. They reuse complete English ASCII/disabled recovery, source/requested review
metadata, source/control/tone provenance and all-or-nothing invalid-output preservation. Literal messages never parse back
into policy, start a helper, scan processes, acknowledge safety, activate coexistence or change the current worker/session.
The ten-minute nonpositive-profit lock, unknown-detection hold, foreign-platform scope limits, native safety/CLI refusal and
no-game-from-Save boundaries remain unchanged and authoritative elsewhere.

Dynamic field/value/before/after/current/frozen-mode envelopes and the private editor-input row are **not** extracted in
this batch. Their values and existing byte-based clipping remain untouched; a literal unit/range in a prompt is not an
atomic localized numeric value. This does not claim complete Game or full-domain typed rendering. Preferences and other
low-level helpers do not import the UI catalog, and ordinary rendering still calls no typed renderer or Unicode backend.

Fixtures check all 528 texts, exact English, unique keys/review/RTL/parameter parity, keyboard/range/reference tokens,
order/direction/width/plain/paint/source provenance, independent wrapped rows and transactional invalid-language/key/tone/
policy/row refusals. The private fixed-predecessor Game harness retains **124416 complete frames / 44064 key transitions,
resulting frames and active/draft machine serializations**, including contextual keys, synthetic maximum basename, timing
boundaries and idle/running/frozen contexts with empty save access. It is not exhaustive input/timing space, real stores/
concurrency, detector or physical-terminal qualification; native store/CLI/PTY/supervisor regressions remain separate.
Exact platform/sanitizer/privacy evidence is in the [execution ledger](architecture/execution-plan.md).

Dynamic Game envelopes, other panels/dashboard/log/raw domains, effective typed native/data-owner/deployment binding, human
review and physical terminal/font/shaping/accessibility remain open. No GPU, installed miner or real game is started by this
batch; physical safety/experience/economics, source, global helper-quarantine and production gates remain unqualified.
