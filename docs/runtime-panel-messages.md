# Runtime shell, contextual editor and limitation notices (P-13t)

M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-118.

**English-only native extraction with separate typed drafts.** Thirty stable `runtime.panel.*` keys across sixteen packs
(480 texts) cover compact/full titles, short-window/leave/review/save/error/focus text, contextual wait editing, no-session/
next-start/CLI/collection/zero-wait limitations and footers. The earlier [thirteen field keys](runtime-field-messages.md)
remain a separate historical domain. Activation-value descriptions in `activationName`, parser/store/raw errors and other
panels remain independent; this does not claim all-domain native translation or production qualification.

Native rendering still selects exact English source. Page/field/scroll order, save/discard and conflict handling, immutable
current runtime, CLI precedence, no deletion/reconnect/restart and stop behavior stay unchanged. Zero remains a valid wait;
the message does not turn host waits into a duty-cycle, hardware tuning or optimizer. History on is a collection request,
not evidence of availability; off preserves existing history, and UI/default saves remain separate. Scope and untouched
credential/donation/hardware notices retain their previous meaning. No renderer starts mining, a collector or a helper.

The contextual editor has one `{input}` role, bounded to the existing **16 printable-ASCII bytes** and invariant under
the typed boundary. It is opaque input, not a localized quantity: empty text, `0`, `1000`, `qDLS` and braces are preserved
without interpretation. The fixed display prefix/cursor underscore remain literals; no control sequence or semantic cursor
is generated. Independent typed wrapping refuses a too-wide atomic input rather than splitting it. Native byte wrapping is
unchanged and is not replaced by this API. Numeric parsing still runs only in the existing confirmation action and keeps
its ASCII integer/range rules; Unicode digits, malformed controls, hidden recovery substitutions and overlong input cannot
gain typed display acceptance or be repaired into a valid setting.

**Q/D/L/S remain input in the editor, not global shortcuts; Ctrl+C still stops.** Every pack retains those tokens and
the existing keyboard tokens/brand/file/CLI/range markers. Save/apply-draft are different actions, and editing does not
implicitly save or apply a work wait. Nonempty raw callback errors still follow their original path, not catalog inference,
translation or redaction. All non-English entries remain machine-assisted drafts and current presentation stays English.

The fixed-domain wrappers preserve role/tone provenance, complete English ASCII/disabled recovery, unknown-language review
metadata and transactional layout/paint/row refusal. Literal entries accept no arguments; editor entries require exactly
the expected named invariant input. Fixtures check all 480 texts, protected tokens, exact English literals, both empty and
maximum input, nonrecursive braces, contextual nonnumeric strings, order/direction/width/paint/wrap and all-wrapper refusal.
The fixed pre-extraction private Runtime harness remains **122880 complete frames / 23040 transitions, resulting frames and
serialized defaults**, with empty save access, six representative waits and explicit zero-valued CLI override. Actual
store/CLI/PTY/supervisor regressions remain separate; these are not physical terminal, all-input-space, save-concurrency or
worker/hardware qualification. Exact evidence is in the [execution ledger](architecture/execution-plan.md).

Activation descriptions, other subpanels/dashboard/log/raw domains and effective typed native/data-owner/deployment binding
remain unfinished. Human review, physical terminal/font/shaping/accessibility and real GPU/game/pool/power/financial/release
gates stay open. No production miner replacement or restart is authorized by this extraction.

[P-13u](activation-messages.md) subsequently extracts the five activation-value descriptions behind a shared ASCII-only
low-level source boundary. This thirty-key shell/editor scope and its historical evidence stay unchanged.
