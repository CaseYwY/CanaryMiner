# Pool-declaration field labels (P-13y)

M-I18N/M-UI; R-I18N-001/002; T-I18N/T-UI/T-CONFIG/T-PRIVACY; D-124.

**English-only native source extraction with independent typed drafts.** Eight stable `pool.field.*` keys in sixteen packs
(128 texts) cover the seven ordered Scope/Mode/TLS-URL/TCP-URL/Plaintext-consent/Add-user-pool/Remove-user-pool labels and
invalid-label recovery. TLS, TCP and URL remain explicit. Non-English entries are machine-assisted drafts, not reviewed
translations or effective native UI.

Only the native panel's private field-label helper changes. Existing native English frames, seven-field order, selected
user/donation scope, contextual editing, explicit confirmation phrases, review/save/cancel and JSON serialization remain
unchanged. Machine mode names, endpoints, numbered slots, consent values/phrases, warnings and raw validation errors are
not translated by this batch. The preferences/parser/fallback gates do not import this catalog. Labels do not create a TLS
factory, verify an endpoint, acknowledge consent, remove a pool, inherit user permission into donation, authorize fallback
or start any network activity. Configured TLS still refuses ordinary startup until separately qualified.

The argument-free `TerminalPoolFieldMessageRequest` and four layout/wrap/paint wrappers accept no endpoints, credentials,
identities, slot numbers or consent input. They preserve requested/source review metadata, complete English ASCII/disabled
recovery, original literal tone, source/control/cell provenance and transactional refusal. They do not represent a complete
pool review document or change protocol/donation semantics. Ordinary native code still invokes no typed renderer or ICU.

Fixtures check all 128 texts, exact English/field order/unique keys/review/RTL/no-parameter/protected-token parity,
order/direction/width/plain/paint/wrapped-row behavior and unchanged output on invalid-language/key/tone/policy/row/null
refusal. A private **fixed-predecessor** harness is checked before extraction and retained unchanged afterward: **258048
complete frame comparisons / 91392 contextual transitions, resulting frames and active/draft declaration serializations**.
It spans unchanged/strict/prefer-without-consent/prefer-with-consent requests, one/two/eight user slots, first/last selection,
independent donation, clean/dirty/removed-slot drafts, idle/running contexts, all seven fields/four pages and widths/heights/
colors, including a synthetic 253-character DNS name. Save access is empty. This is representative host-state comparison,
not exhaustive endpoint/parser space, live-store concurrency, TLS/trust/fallback or real-network qualification; native store/
CLI/PTY and transport regressions are separate. Exact evidence is in the [execution ledger](architecture/execution-plan.md).

Pool shell/warnings/dynamic values/private editor input, other subpanels/dashboard/log/raw domains, effective typed native/
data-owner/deployment binding, human translation review and physical terminal/font/shaping/accessibility remain open.
Normal TLS/trust/auxiliary egress/fallback/donation/deployment qualification and real GPU/game/financial/power/safety/global
quarantine/release gates are not supplied by display labels.
