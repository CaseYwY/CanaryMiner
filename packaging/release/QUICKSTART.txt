CanaryMiner @VERSION@ - Linux x86-64 quick start
==================================================

Requirements
- x86-64 Linux with glibc @GLIBC@ or newer (Ubuntu 22.04, 24.04 and later).
- NVIDIA RTX 50-series GPU (Blackwell, SM120). This release does not run on other GPUs.
- @MIN_DRIVER@
- The driver's libcuda.so.1 is the only NVIDIA library this archive needs. The CUDA toolkit is not required.

Start
1. Copy the example configuration and set your public PRL payout address:
     cp config.example.json config.json
   Edit "wallet" in config.json. Use a public payout address only. Never put wallet secrets or passwords in the file.
2. Check the GPUs and run the offline self-test:
     ./canary-miner list-devices
     ./canary-miner selftest
3. Start mining:
     ./canaryminer.sh --config config.json

Developer donation
- On by default: 1% of productive mining time goes to the developer. The README explains exactly how it works.
- Turn it off with --no-donation, or set "donation": false in config.json. The command-line flag wins over the config.
- ./canary-miner --help lists every option.

Stats
- The stats endpoint is loopback-only at 127.0.0.1:8085 by default: /api/v1/stats and /api/v1/version.

Verify this download
  sha256sum -c SHA256SUMS
